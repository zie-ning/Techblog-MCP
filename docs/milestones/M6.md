  - MCP prompt(`/techblog`)는 지원하는 클라이언트에서만 동작한다. Claude Code CLI는 동작, Claude 데스크톱 앱(Code 탭)은 "사용할 수 없는 명령어"로 실행되지 않음 (시나리오 9)
