# M9. 원격 HTTP 서버 (확장)

> 상태: **대기** · 직무 근거: 백엔드 · 허브: [docs/README.md](../README.md)

M8의 데이터 배포 구조를 재사용하므로 M8 다음에 한다.

## M8에서 넘어온 항목

- **DB 준비**: 원격 서버도 M8 4단계 방식(`db.cached_db`, `db.check_for_update`)으로 최신 Release DB를 하루 한 번 확인해 받는다. 다만 원격 서버는 오래 떠 있으므로 "다음 기동부터 새 DB"가 아니라 실행 중 교체가 필요한지 착수 시 정한다
- **PyPI 전환 보류의 전제**: 설치 없이 URL로 연결하는 원격 서버가 설치 편의 문제를 해결한다는 판단으로 PyPI 전환을 보류했다 ([기획.md](../기획.md#배포-로드맵))

## 작업

- stdio는 유지하고 Streamable HTTP 방식을 추가해 클라우드에 배포
- 요청 제한, 구조화 로깅, 지연 시간 모니터링

## 완료 기준

URL만으로 연결해 쓸 수 있음. 호스팅 방식과 비용은 착수 시 결정
