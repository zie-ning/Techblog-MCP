## 진행 방식

실행 계획 전문은 [.claude/plans/m4-full-extract.md](../../.claude/plans/m4-full-extract.md)에 있다.

| 항목 | 방식 |
| --- | --- |
| 추출 실행 | Batch API를 구현하지 않고 기존 동기 CLI를 `--workers`로 병렬 실행 (사용자 결정). 실패한 글은 같은 명령을 다시 돌려 회수 |
| 분류 목록 검토 | 블로그당 25편(200편) 표본을 먼저 `data/`에 추출해 분포를 보고 목록을 확정한 뒤 나머지를 추출 (사용자 결정). 목록이 바뀌면 표본만 재추출 |
| 기술 사전 보강 | 전체 추출 뒤 `pipeline.normalize` 리포트로 빈도 높은 이름부터 보강하고 `--apply`로 재정규화 |
