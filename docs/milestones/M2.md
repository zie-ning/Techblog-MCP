## 작업

- 나머지 7개 블로그 수집기 (수집 경로와 주의점은 [기획.md](../기획.md#블로그-수집-조사-결과-2026-09-28-기준)의 조사 결과)

  - 사이트맵 + HTML: 카카오페이, LY
  - 사이트맵 + Next.js 스크립트 데이터 파싱: 카카오

## 완료 기준

8곳 약 1,360편의 원문과 발행일 확보, 파서 테스트 통과

## 진행 상황

실제로 조회해 보니 조사 결과와 다른 점이 있어 수집 방식을 보정했다 (컬리 피드에 본문 없음, 카카오는 Nuxt, 토스 본문은 글 페이지 HTML, D2 목록 본문은 잘림). 보정 내용과 사전 제외 결정은 [기획.md](../기획.md#데이터-수집)에 반영했다.

| 블로그 | 수집 방식 | 저장 | 비고 |
| --- | --- | --- | --- |
| 카카오 | 사이트맵 `/posts/N` (lastmod로 1차 필터) → 글 페이지의 `__NUXT_DATA__`에서 본문·발행 시각 | 211 | |
| LY | 사이트맵에서 `/ko/{slug}`만 → 글 페이지 본문 영역 | 210 | 번역 안내·공유 버튼·작성자 소개 제외 |
| 우아한형제들 | WordPress REST API (시스템 curl로 요청) | 182 | WAF가 httpx 요청을 403으로 차단. 운영 측 허락을 받아 이 호스트만 curl 전송 계층 사용 ([수집 예절](../기획.md#데이터-수집)) |
| 토스 | 공개 API로 목록·발행일·카테고리 → 글 페이지 `<article>` 본문 | 179 | Design, 외부 링크 글(본문 없음) 제외 |
| 올리브영 | RSS 전문 (M1) | 159 | 기간을 한국 시간 기준으로 바꿔 경계일 글 1편 추가 |
| D2 | 목록 API로 기간 필터 → 상세 API 본문 | 156 | news 제외 |
| 카카오페이 | 사이트맵 `/post/{slug}/` → 글 페이지 (날짜가 사이트맵에 없어 모두 받은 뒤 필터) | 114 | 기간 밖 50편 |
| 컬리 | RSS로 목록·발행일 → 글 페이지 본문 section | 51 | 피드 description은 요약뿐 |
| **합계** | | **1,262** | 실패 0건 |

- 봇 확인 우회 원칙 변경: "우회 금지" → "운영 측 허락을 받은 경우 브라우저 위장 없이 일부 허용" ([기획.md](../기획.md#데이터-수집)). 허락받은 호스트만 `CurlTransport`(시스템 curl)로 요청
- 공통 기반: 사이트맵 파서, 글별 수집 루프(캐시된 글은 건너뛰어 중단 후 이어받기, 한 편 실패해도 계속 진행하고 실패 목록 보고), `collect all`·`--refresh`
- 파서 테스트: 블로그마다 실제 응답 구조를 본뜬 축약 샘플(`tests/fixtures/`, 본문은 임의 문장)로 목록·발행일·본문 추출·제외 규칙·기간 경계를 검사
- 수집 기간 경계를 한국 시간 기준으로 판단하도록 수정 (UTC 발행일이 하루 어긋나 경계일 글이 빠지던 문제)
- 블로그마다 평문화(`html_to_text`) 결과를 확인해 본문 누락·메뉴 혼입이 없고 코드 블록이 보존됨을 확인
