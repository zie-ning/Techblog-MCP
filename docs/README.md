## 문서 관리 규칙

- 마일스톤 상태가 바뀌면 해당 마일스톤 문서의 상태 줄과 이 문서의 "마일스톤 현황"을 **함께** 고친다.
- 한 마일스톤에서 발견해 다른 마일스톤으로 넘기는 과제는 **받는 쪽 문서**의 "넘어온 항목"에 적고, 보낸 쪽에는 어디로 넘겼는지만 남긴다.
- 설계 결정은 마일스톤 문서가 아니라 [기획.md](기획.md)에 기록하고, 마일스톤 문서에서는 링크로 참조한다.
- 상태 표시: ✅ 완료 · 🔄 진행 중 · ⏳ 대기
