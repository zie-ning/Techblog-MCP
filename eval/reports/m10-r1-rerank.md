# M10 R1: 리랭커 판정 가능성

후보: 질문마다 BM25(서버 가중치)와 OpenAI large 임베딩 상위 50건씩을
RRF로 합친 상위 50건. 리랭커에는 항목의 제목 + 문제 상황 + 해결 방법
+ 성능·운영 + 기술(임베딩 입력과 같은 텍스트)을 넣는다.
'≥' 설정의 기준선은 아래 '1위 점수로 가르기'의 최적 기준선이다.

- 검색 DB: 항목 1315개, 스키마 6
- 평가셋: 질문 30개. 지표 정의는 eval/search/README.md
- 관련도 기준이 없는 설정은 상위 10건을 결과로 본다
