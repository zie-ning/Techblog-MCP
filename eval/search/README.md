# 검색 평가셋

M5 검색 평가용 질문 30개와 정답 라벨. 파일은 [queries.toml](queries.toml), 형식은 [../search_eval.py](../search_eval.py)의 `EvalQuery`, 실행은 아래와 같다.

```bash
uv run python eval/search_eval.py                                   # 현재 설정 → eval/reports/m5-baseline.md
uv run python eval/search_eval.py --name w-title3 --weights title=3 # 가중치를 바꿔 비교
```

임베딩 실험은 OpenAI 모델을 쓴다(`.env`의 `OPENAI_API_KEY`). 항목 임베딩은 `eval/search/embeddings/`(git 제외)에 캐시된다. 모델 목록은 [../search_embed.py](../search_embed.py)의 `MODELS`. M5 판정 풀에 쓴 로컬 모델(fastembed MiniLM)은 도입하지 않기로 해 지웠다.

```bash
uv run python eval/search_eval.py --name emb-openai-small --embedding openai-small
uv run python eval/search_eval.py --embedding openai-small --embedding openai-large --pool 후보.md
```

문서 확장(E7)과 질의 재작성(E8) 실험은 LLM(기본 `gpt-5.6-luna`)으로 확장 텍스트와 재작성 검색어를 만든다. 생성물과 확장 DB는 `eval/search/llm_cache/`(git 제외)에 캐시된다. 생성 지시문은 [../search_llm.py](../search_llm.py)에 있다.

```bash
uv run python eval/search_experiments.py e7 e8
```

`--pool`은 평가 대신 판정용 후보 목록을 만든다. 이미 판정한 항목은 라벨이, 새 후보는 `[미판정]`이 붙는다.

## 질문 구성 (M5 사용자 결정)

| 출처 (`source`) | 수 | 내용 |
| --- | --- | --- |
| `M1` | 약 10 | M1 실사용 시나리오와 M5 관찰 기록의 검색어. 에이전트가 실제로 넣은 형태(긴 검색어, 필터 포함)를 그대로 쓴다 |
| `데이터` | 약 15 | 1,315개 항목의 분포에서 뽑은 주제. 문제 유형 21개가 고르게 들어가게 하고, 짧은 검색어·긴 검색어·필터 사용을 섞는다 |
| `없는 주제` | 약 5 | DB에 사례가 없는 주제. "결과 없음"을 제대로 판정하는지 본다. `관련` 라벨이 있으면 안 된다 |

질문은 코딩 에이전트가 설계를 시작하기 전에 `search`에 넣을 법한 문장으로 쓴다.

## 판정

- 후보 풀: 여러 검색 설정(BM25 변형, 임베딩 모델별)의 상위 20건과 필터 검색 결과를 합친다. 임베딩 후보를 넣는 것은 하이브리드 검색이 라벨에서 불리해지지 않게 하기 위해서다.
- 판정은 Claude Code 세션이 항목의 제목·문제 상황·해결 방법을 질문과 대조해 하고, 이유를 남긴다. 사용자 검수 없이 진행하고 애매한 질문만 보고한다 (M5 사용자 결정).
- 판정한 후보는 모두 `judged`에 넣는다. `labels`에는 `관련`·`일부 관련`과 이유를 적고, 판단이 갈릴 만한 `무관`만 이유와 함께 적는다. `judged`에 있고 `labels`에 없으면 무관, `judged`에 없으면 미판정이다.
- 실험에서 미판정 항목이 결과에 나오면 리포트의 "미판정" 수로 드러난다. 그 항목을 판정해 평가셋에 추가한다.

| 라벨 | 기준 |
| --- | --- |
| 관련 | 질문의 문제를 직접 다룬 항목. 에이전트가 이 질문에 답할 때 소개해야 할 사례 |
| 일부 관련 | 같은 문제를 다른 각도에서 다뤄 비교 자료가 되는 항목(예: 같은 회사가 다른 과업에서 다른 선택을 한 사례), 또는 질문의 일부만 다룬 항목 |
| 무관 | 단어만 겹치거나 다른 문제를 다룬 항목 |

## 지표

- **정답은 `관련`만** 센다. `일부 관련`은 정답도 잡음도 아니다 (M5 사용자 결정).
- **Recall@5, Recall@10**: 상위 k건에 든 정답 수 ÷ min(정답 수, k). 정답이 k개보다 많은 넓은 주제도 상위 k건이 모두 정답이면 1.0이다 (M5 사용자 결정).
- **MRR**: 첫 정답 순위의 역수 평균.
- **글 단위 지표**: 같은 글의 항목은 하나로 보고(처음 나온 순위) 같은 방식으로 계산한다. 1글 = N항목 구조의 영향을 보기 위함.
- **관련도 기준 지표**: 없는 주제 질문 중 결과 0건 비율, 질문당 결과 수, 결과 중 무관 비율(판정된 결과만 분모), `일부 관련` 중 결과에 남은 비율.
- 관련도 기준이 없는 설정은 상위 10건(서버가 돌려줄 최대 건수)을 결과로 본다.
